# Supported Hardware for the DeepSparse Engine

With support for AVX2, AVX-512, and VNNI instruction sets, the DeepSparse Engine is validated to work on x86 Intel (Haswell generation and later) and AMD CPUs running Linux.
Mac and Windows require running Linux in a Docker or virtual machine.
